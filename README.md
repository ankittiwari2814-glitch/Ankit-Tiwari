# Ankit Tiwari - Director Portfolio

A modern, responsive filmmaker portfolio website showcasing director work, commercials, and music videos.

## Features

- 🎬 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- 🎥 **Embedded Videos** - YouTube and Vimeo video integration
- 🌓 **Dark Theme** - Modern dark UI with vibrant accent colors
- 📱 **Mobile Navigation** - Hamburger menu for mobile devices
- ✨ **Smooth Animations** - Scroll animations and transitions
- 📧 **Contact Form** - Easy way for clients to reach out
- ⚡ **Fast Loading** - Optimized for performance

## How to View

1. Open `index.html` in your web browser
2. Navigate through sections using the menu
3. All videos are embedded and ready to play

## Deployment

### GitHub Pages
1. Repository settings → GitHub Pages
2. Select main branch as source
3. Your site will be live at your GitHub Pages URL

### Other Platforms
- **Netlify**: Connect your GitHub repo
- **Vercel**: Import your GitHub repository
- **Traditional Hosting**: Upload files via FTP

## Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --secondary-color: #ff6b35;
    --accent-color: #f7931e;
}
```

### Content
Edit `index.html` to update:
- Contact information
- Portfolio items
- Social media links
